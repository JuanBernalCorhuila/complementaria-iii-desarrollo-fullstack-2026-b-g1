# Semana 2 - Maqueta una interfaz web

Actividad opcional de refuerzo.

## Qué hace

- HTML5 semántico: `header`, `main`, `section`, lista y botón.
- CSS3 con flexbox para el layout de la tarjeta.
- JavaScript: al hacer clic en el botón, se muestra/oculta un mensaje (`classList.toggle`).

## Cómo probar

Abrir `index.html` directamente en el navegador.
