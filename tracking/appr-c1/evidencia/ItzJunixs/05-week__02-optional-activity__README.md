# Semana 5 - Frontend inicial (cierre C1)

Actividad opcional de refuerzo.

Esta semana pide integrar un mini-frontend: una vista que consume una API, muestra datos,
maneja estados de carga/datos/error, con diseño limpio y documentación en el README.

Esto ya está resuelto en `c1-practical-exam/`, específicamente:

- `c1-practical-exam/problem-1/` - HTML semántico + CSS + JavaScript (fundamentos).
- `c1-practical-exam/problem-2/` - consumo de API con `fetch`, estados de carga/datos/error.
- `c1-practical-exam/README.md` - documentación de cómo probar cada parte.

Ver `c1-practical-exam/` para la entrega completa.
