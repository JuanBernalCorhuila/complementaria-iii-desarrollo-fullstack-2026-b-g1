# Semana 4 - Componente que consume datos

## Overview
This application is a React frontend built with Vite that displays a personalized video game library. It successfully consumes data using the JavaScript fetch API method. The interface effectively manages and renders three required application states including loading, data display, and error handling. The layout is structured cleanly using reusable components to provide an intuitive user experience.

## How to Run
1. Open terminal in the project folder.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
