Problema 3 — Framework y SPA

¿Qué es un componente?

Un componente es una parte reutilizable de una interfaz. Por ejemplo, un botón, un menú o una lista pueden funcionar como componentes independientes. 


Componente Usuario
    ├── Nombre
    ├── Email
    └── Botón

¿Qué es el estado?

El estado representa información que puede cambiar durante la ejecución de una aplicación. 


estado = {
    cargando: false,
    usuarios: [],
    error: null
}

¿Qué hace el enrutamiento?

El enrutamiento permite mostrar diferentes vistas según la URL o la ruta seleccionada por el usuario. 


/            → Inicio
/usuarios    → Usuarios
/contacto    → Contacto

¿Por qué una SPA necesita una API?

Una SPA necesita una API para comunicarse con el servidor y obtener o modificar datos sin tener que recargar completamente la página.

Una API permite separar el frontend del backend y facilita que la aplicación pueda consumir información de forma dinámica.

English requirement

An SPA loads a single page and updates its content dynamically without reloading the entire page. An MPA loads a new page from the server when the user navigates to a different section.
