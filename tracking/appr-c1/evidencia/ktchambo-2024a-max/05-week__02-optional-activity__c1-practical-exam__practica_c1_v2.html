Problema 1

Lenguajes que usamos en el desarrollo web:

  • HTML5 - estructura de la pagina
  • CSS3 - estilos visuales
  • JavaScript - comportamiento e interactividad

Funciono! Esto lo hizo JavaScript

HTML es el lenguaje base que estructura el contenido de la pagina, sin el no habria nada que mostrar. CSS le da la apariencia a ese contenido, los colores, el tamaño de las letras, como se distribuyen los elementos, etc. JavaScript es el que le da vida a la pagina haciendo que responda a lo que hace el usuario. Los tres son distintos pero trabajan juntos para que una pagina web funcione bien.

    Problema 3

    Un componente es como un bloque de construccion de la interfaz, es una pieza reutilizable que tiene su propia estructura y logica. Por ejemplo en React: 

    function Usuario({ nombre, correo }) {
    return (
        <div>
            <p>{nombre}</p>
            <p>{correo}</p>
        </div>
    );
}

    El estado es la informacion interna de un componente que puede cambiar. Cuando el estado cambia React actualiza lo que se muestra en pantalla automaticamente. Por ejemplo si tengo un contador que sube al hacer clic, ese numero es el estado. El enrutamiento permite que la aplicacion muestre diferentes vistas segun la URL en la que este el usuario, sin recargar la pagina.

    Una SPA necesita una API porque toda la interfaz corre en el navegador pero los datos estan en el servidor. La API es el puente para que el frontend pueda pedir o enviar datos sin recargar. Sin una API la SPA estaria limitada a solo lo que tiene cargado localmente y no podria ser dinamica.

    English section:

    A Single Page Application works by loading one HTML file and then changing the content dynamically with JavaScript, so the user never sees a full page reload when navigating. A Multi-Page Application loads a completely new page from the server every time the user clicks a link, which causes a visible reload each time. The main difference is that SPAs feel smoother and faster, but they are more complex to build compared to MPAs.
