# Rick and Morty Characters API

## Overview

This project is a frontend application that displays characters from the Rick and Morty series. The application consumes data from the Rick and Morty public API using the JavaScript fetch function. Each character is displayed in an organized card with an image, name, status, and species. The application handles a loading state while the information is being requested from the API. It also handles an error state when the API request fails. When the request is successful, the application displays the character data in a responsive grid.

## API

The application uses the following public API:

Rick and Morty API
https://rickandmortyapi.com/api/character

## Technologies

- HTML5
- CSS3
- JavaScript
- Fetch API

## How to Run

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. The application will load the characters automatically.

## States

### Loading

Displays a loading message while the API request is being processed.

### Data

Displays the characters returned by the API.

### Error

Displays an error message if the API request fails.
