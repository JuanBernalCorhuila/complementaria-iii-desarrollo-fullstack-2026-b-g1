Rol de cada lenguaje

  • HTML: define la estructura y el contenido de la página (el encabezado, la lista, el botón). Es el "esqueleto" de la vista.
  • CSS: se encarga de la apariencia visual (colores, espaciados, bordes). Aquí lo aporta Bootstrap como framework, más el archivo style.css propio para ajustes personalizados.
  • JavaScript: agrega comportamiento e interactividad. Al hacer clic en "Agregar tarea", JS crea un nuevo elemento de lista y actualiza el contador — sin JS, el botón no haría nada.

    Problema 3 — Framework y SPA

    ¿Qué es un componente?

    Un componente es un bloque de interfaz reutilizable que agrupa su propia estructura, estilo y lógica (por ejemplo, una tarjeta de usuario o un botón con su comportamiento). Se puede usar varias veces en distintas partes de la app sin repetir código.

    ¿Qué es el estado?

    El estado es la información que puede cambiar mientras la app está en uso (por ejemplo, la lista de tareas o si se está cargando algo). Cuando el estado cambia, la interfaz se vuelve a mostrar automáticamente reflejando ese cambio.

    ¿Qué hace el enrutamiento (routing)?

    El enrutamiento permite mostrar diferentes vistas dentro de una misma página, cambiando la URL sin que el navegador recargue todo el sitio.

    Pseudocódigo de ejemplo

    componente TarjetaUsuario(usuario):
    mostrar usuario.nombre
    mostrar usuario.email

estado listaUsuarios = []

al iniciar la app:
    listaUsuarios = obtenerUsuariosDesdeAPI()

router:
    ruta "/"             -> mostrar PaginaInicio
    ruta "/usuarios"      -> mostrar ListaUsuarios(listaUsuarios)
    ruta "/usuarios/:id"  -> mostrar DetalleUsuario(id)

    ¿Por qué una SPA necesita una API?

    Una SPA (Single Page Application) carga una sola página HTML y luego actualiza su contenido dinámicamente con JavaScript. Como no recarga el servidor para cada vista, necesita una API para pedir y enviar datos "por detrás" (con fetch) cada vez que el usuario navega o interactúa, manteniendo la información actualizada sin recargar toda la página.

    English requirement

    A Single Page Application (SPA) loads a single HTML page once and then updates its content dynamically using JavaScript, without reloading the whole page. In contrast, a Multi Page Application (MPA) loads a new HTML page from the server every time the user navigates to a different section, which usually makes navigation feel slower.
