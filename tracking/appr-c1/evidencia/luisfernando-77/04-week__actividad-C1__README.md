# TruequeLocal - Activity 1 (Week 4)

## Overview
TruequeLocal is a web application designed to allow users to trade items they no longer use for products they need. The application consumes a public API via HTTP GET requests using the fetch API to retrieve available item listings. The frontend handles three core UI states: a loading spinner while fetching data, a grid display when data is successfully retrieved, and an error message box if the request fails. It features a responsive layout with CSS Grid and modern card components to enhance user experience.

## How to Run
1. Clone this repository to your local machine.
2. Navigate to `04-week/actividad-C1/`.
3. Open `index.html` in any modern browser (or use VS Code Live Server extension).
