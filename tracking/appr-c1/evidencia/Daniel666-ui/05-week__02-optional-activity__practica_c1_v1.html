El boton funciono correctamente con JavaScript

HTML es el lenguaje que le da estructura a la pagina, define los elementos que van a aparecer como titulos, listas, botones, etc. CSS se encarga de la parte visual, los colores, tamaños y como estan ordenados los elementos en pantalla. JavaScript es el que hace que la pagina sea interactiva, por ejemplo que al hacer clic en un boton pase algo. Los tres trabajan juntos, cada uno con un rol diferente.

Problema 2

    Para crear un recurso nuevo usaria el metodo POST porque es el que se usa para enviar datos nuevos al servidor. Para borrar un recurso usaria DELETE, que le indica al servidor que elimine ese elemento. El metodo GET que use en el fetch solo sirve para leer datos sin modificar nada.

    Problema 3

    Un componente es una parte de la interfaz que tiene su propia logica y se puede reutilizar en distintos lugares de la aplicacion. Por ejemplo en React un componente basico seria asi: 

    function Tarjeta({ titulo }) {
    return (
        <div>
            <h3>{titulo}</h3>
        </div>
    );
}

    El estado es la informacion que guarda un componente y que puede cambiar. Cuando el estado cambia, el componente se vuelve a mostrar con los datos nuevos. Por ejemplo si cargo una lista de usuarios, esa lista es estado. El enrutamiento es lo que permite navegar entre distintas vistas o paginas dentro de la aplicacion sin que el navegador recargue toda la pagina.

    Una SPA necesita una API porque aunque la pagina no se recarga, igual necesita obtener o guardar datos en el servidor. La unica forma de hacerlo de manera asincrona es mediante peticiones HTTP a una API. Sin API la SPA no podria mostrar datos reales.

    English:

    A Single Page Application loads only once in the browser and updates the content dynamically using JavaScript without reloading the full page. A Multi-Page Application sends a new request to the server each time the user navigates, causing a full page reload every time. SPAs feel faster and more like a desktop app, while MPAs are simpler to build but feel slower when navigating.
