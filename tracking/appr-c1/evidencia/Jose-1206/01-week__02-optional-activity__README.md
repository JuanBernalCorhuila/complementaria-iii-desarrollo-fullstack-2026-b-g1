## Un poco de mi historia

Soy estudiante de Ingeniería de Sistemas, actualmente en sexto semestre. Desde que empecé la carrera me atrajo la parte de construcción de software más que la teoría pura: me gusta ver una idea convertirse en algo que se puede usar, hacer clic y probar. Por eso, con el paso de los semestres me fui inclinando cada vez más hacia el desarrollo de aplicaciones web, tanto en la parte visible para el usuario como en la lógica que corre "detrás de cámaras".

Este semestre estoy cursando **Desarrollo Fullstack**, una materia que me tiene bastante entusiasmado porque conecta piezas que había visto por separado en semestres anteriores: interfaces, servidores, bases de datos y la forma en que todo eso se integra en un solo producto funcional.

## 🛠️ Habilidades técnicas

- **Frontend:** Next.js (React) — construcción de interfaces, ruteo, renderizado del lado del servidor y consumo de APIs.
- **Backend:** NestJS — arquitectura modular, controladores, servicios e inyección de dependencias sobre Node.js.
- **Lenguajes:** Java (programación orientada a objetos, estructuras de datos, lógica de negocio) y JavaScript/TypeScript.
- **Bases de datos:** diseño de modelos relacionales, consultas SQL y manejo básico de bases de datos NoSQL.
- **Otras herramientas:** Git y GitHub para control de versiones, y conceptos generales de arquitectura cliente-servidor y APIs REST.

## 🎯 Lo que busco en esta materia

Quiero reforzar la conexión entre el frontend y el backend: entender cómo una interfaz consume información real desde una API, cómo se manejan los distintos estados de una aplicación (cargando, con datos, con errores) y cómo se documenta y versiona un proyecto de forma profesional. Mi objetivo a mediano plazo es poder construir aplicaciones completas de extremo a extremo, desde la base de datos hasta la experiencia de usuario final.
