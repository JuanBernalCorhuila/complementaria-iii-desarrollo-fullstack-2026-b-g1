Notas del diseño

Cada usuario se muestra en una tarjeta con una franja naranja a la izquierda: el nombre arriba, el correo debajo en gris y la ciudad alineada a la derecha. Esa tarjeta se repite tantas veces como usuarios lleguen, por eso se resuelve como un componente aparte.

Los dos botones y el encabezado se quedan fijos en los tres estados, para que el usuario siempre pueda reintentar sin importar qué haya pasado. El boton "Probar el error" apunta a una direccion invalida a proposito, y sirve para demostrar el estado de error.

Hay un cuarto caso contemplado: si la API responde bien pero la lista viene vacia, se muestra el aviso "No hay usuarios para mostrar" en el mismo lugar del mensaje de estado.
