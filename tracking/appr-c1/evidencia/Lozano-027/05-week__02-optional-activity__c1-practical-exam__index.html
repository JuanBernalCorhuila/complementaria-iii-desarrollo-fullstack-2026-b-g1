    Problem 3 - Framework and SPA

    Component

    A component is a reusable part of the user interface.

    State

    State is information that can change during the application.

    Routing

    Routing allows the application to navigate between different views.

    Why does an SPA need an API?

    An SPA needs an API to communicate with the server and obtain or send data.

    SPA vs MPA

    An SPA uses one main page and changes its content dynamically without reloading the entire page. An MPA loads a new HTML page when the user navigates to another section.
