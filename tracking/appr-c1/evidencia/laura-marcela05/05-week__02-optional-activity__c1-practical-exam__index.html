    Rol de cada lenguaje (Problema 1):
    • HTML: define la estructura (encabezado, lista, botón).
    • CSS: define la apariencia (colores, bordes, espaciado).
    • JavaScript: define el comportamiento (agregar receta al hacer clic, consumir datos).

    Framework y SPA (Problema 3)

    Un componente es una parte de la interfaz que se puede reutilizar, por ejemplo, cada elemento de la lista de recetas. El estado es la información que puede cambiar, como las recetas cargadas y el mensaje de carga o error.

    El enrutamiento permite cambiar de vista según la dirección URL sin volver a cargar toda la página. Una SPA necesita una API para solicitar y enviar datos al servidor mientras la interfaz continúa funcionando en una sola página.

    Ejemplo mínimo: un componente muestra una receta y, cuando cambia el estado, la lista se actualiza.

    SPA and MPA: An SPA loads one main page and updates its content without reloading the whole page. An MPA loads a new page from the server when the user navigates to another section.
