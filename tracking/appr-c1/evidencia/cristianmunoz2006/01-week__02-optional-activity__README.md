## Expectativas del curso

- Entender de forma sólida cómo se conecta un **frontend** con una
  **API**, manejando correctamente los estados de carga, datos y error.
- Aprender buenas prácticas de **Git y GitHub** para versionar proyectos
  de forma ordenada y colaborativa, tal como se pide en las entregas.
- Ir construyendo, semana a semana, una base de proyectos reales que
  sirvan como portafolio para futuras oportunidades laborales.
- Fortalecer mi criterio para diseñar interfaces claras, ordenadas y
  fáciles de mantener, no solo funcionales.
