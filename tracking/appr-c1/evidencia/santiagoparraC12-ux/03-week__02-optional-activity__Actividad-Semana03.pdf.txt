Objetivos
• Diseñar un mockup de la vista.
• Consumir una API y manejar carga/error.
1. Enunciado
1. Diseña el mockup de una vista (lista de elementos).
2. Consume una API pública con fetch, muestra los datos en la lista.
3. Maneja los estados cargando, datos y error.
2. Requisitos
• Vista que consume una API con estados.
3. Cómo entregar (por GitHub)
Las entregas se realizan en tu fork del repositorio de la clase, dentro de la carpeta de esta semana.
Si nunca has usado GitHub, sigue el [Manual de Entrega por GitHub](https://code-
corhuila.github.io/ova-web/manuales/Manual-Entrega-GitHub.pdf) paso a paso.
1. Haz fork del repositorio de la clase y clónalo.
2. Coloca tu entrega en la carpeta `03-week/`.
3. Sube los cambios: git add . · git commit -m "Entrega semana 03" · git push.
4. Ten tu repo de perfil con el bloque CONFIG (FULL_NAME + GITHUB_USER).
