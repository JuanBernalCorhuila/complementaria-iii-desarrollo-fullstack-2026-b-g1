# User List App

## Overview

This is a simple web application that displays a list of users.
The application uses a local JSON API example to obtain user information.
The frontend uses JavaScript and the fetch() method to request the data.
Each user is displayed with their name, email, and city.
The application handles three states: loading, data, and error.
The loading state is shown while the information is being requested.
The data state displays the users when the request is successful.
The error state shows a message when the data cannot be loaded.

## Technologies

- HTML
- CSS
- JavaScript
- JSON
- Fetch API

## Project Structure

- `index.html` - Main structure of the application.
- `style.css` - Styles and layout of the application.
- `script.js` - Fetches the data and displays the users.
- `users.json` - Example API data.
- `user list.png` - Application mockup.

## How to Run

1. Open the project in Visual Studio Code.
2. Install and use the Live Server extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
5. The application will open in the web browser.
